# 4학년 교과 어휘 학습 앱

초등학교 4학년 학생이 **국어 · 사회 · 과학** 교과서의 핵심 어휘를
대시보드 → 개별화 학습 → 퀴즈 → 오답 복습 흐름으로 익히는 학습 웹앱입니다.
교사는 학급 전체와 학생별 이해도를 확인하고, 연구용 자료를 CSV로 내려받을 수 있습니다.

React + Vite + TypeScript + React Router로 만들었고, **Supabase**(PostgreSQL)로
로그인과 모든 학습 기록을 저장합니다. 음성은 표준 Web Speech API를 사용합니다.

**학생용**
- 로그인하면 **대시보드**가 먼저 열립니다 (정답률 · 푼 문제 · 오답 · 반복 오답 · 복습 완료 · 연속 학습일)
- **개별화 학습**: 내 오답 → 미숙달 → 새 어휘 순으로 5~10분 세트를 자동 구성
- **오늘의 단어**: 매일 한 어휘를 뜻·예문·음성으로 익히고 바로 퀴즈로 확인
- **오답 노트**: 반복해서 틀린 어휘를 빨간 카드로 강조, 복습 완료 기록
- **선생님이 내준 학습**: 배정된 어휘 세트를 학습하고 점수를 남김

**교사용** (`/teacher`, PIN 필요)
- **전체 현황**: 학생 수 · 평균 정답률 · 총 학습 횟수 · 많이 틀린 단어 · 도움이 필요한 학생
- **학생별 현황**: 정답률·학습량·오답·마지막 학습일 표, 학생별 상세 화면
- **오답 분석**: 교과/단원 필터, 어휘별·단원별 오답률, 학생별 반복 오답
- **학습 배정**: 전체 또는 특정 학생에게 어휘 세트 배정, 수행 현황 확인
- **자료 내보내기**: 익명 ID 기준 연구용 CSV 6종

## 1. 실행 방법

필요 도구: [Node.js](https://nodejs.org) 18 이상

```bash
npm install      # 의존성 설치 (처음 한 번)
npm run dev      # 개발 서버 실행 → 안내된 주소 접속
npm run build    # 배포용 빌드 (dist/ 폴더 생성)
npm run preview  # 빌드 결과 미리보기
```

> ⚠️ 로그인·저장 기능을 쓰려면 먼저 **2. Supabase 설정**을 끝내고
> `.env` 파일에 접속 키를 넣어야 합니다. 키가 없으면 로그인 화면에
> "서버 접속 정보가 설정되지 않았습니다" 안내가 표시됩니다.

## 2. Supabase 설정 (최초 1회)

1. [supabase.com](https://supabase.com)에서 무료 프로젝트를 만듭니다.
2. 좌측 메뉴 **SQL Editor → New query**에서 `supabase/` 폴더의 SQL 파일을
   **순서대로** 붙여넣고 **Run** 합니다.

   | 순서 | 파일 | 내용 |
   |---|---|---|
   | 1 | `schema.sql` | 학생 계정 · 오답 · 통계 (기본) |
   | 2 | `schema_v2.sql` | 문항 응답 로그 · 어휘 숙달 · 익명 ID · 대시보드 |
   | 3 | `schema_p2.sql` | 개별화 학습 세트 |
   | 4 | `schema_p3.sql` | 반복 오답 · 복습 완료 기록 |
   | 5 | `schema_p4.sql` | 교사 대시보드 (전체/학생별) |
   | 6 | `schema_p5.sql` | 오답 분석 · 학습 배정 |
   | 7 | `schema_p6.sql` | 연구용 데이터 내보내기 |

   > 각 파일은 여러 번 실행해도 안전하도록(`create or replace`,
   > `create table if not exists`) 작성되어 있습니다.
3. **Project Settings → API**에서 다음 두 값을 복사합니다.
   - `Project URL`
   - `anon public` 키
4. 프로젝트 루트에 `.env` 파일을 만들고(`​.env.example` 복사) 값을 채웁니다.

   ```bash
   VITE_SUPABASE_URL=https://xxxx.supabase.co
   VITE_SUPABASE_ANON_KEY=eyJhbGciOi...
   ```

5. `npm run dev`로 다시 실행하면 로그인/회원가입이 동작합니다.

> 🔐 비밀번호는 평문이 아니라 bcrypt 해시로 저장되며, 검증은 서버(Supabase
> 함수) 안에서만 이루어집니다. `students` 테이블은 RLS로 직접 조회가 차단됩니다.

## 4. 교사가 어휘 데이터를 수정하는 방법

모든 어휘는 한 파일에 모여 있습니다.

> 📄 `src/data/vocab.ts` 의 **`VOCAB_DB`** 배열

어휘 하나를 아래 형태로 추가/수정/삭제하면 됩니다.

```ts
{
  id: "so-10",                                   // 겹치지 않는 고유 값
  word: "축제",                                  // 어휘
  subject: "사회",                               // "국어" | "사회" | "과학"
  unit: "우리 지역의 문화",                       // 단원 이름
  easy_meaning: "여러 사람이 모여 즐기는 행사",   // 쉬운 뜻
  example_sentence: "우리 지역에서는 해마다 봄에 축제가 열려요.", // 예문
  image_url: "🎉",                               // 이모지 1개
}
```

⚠️ **중요**: `example_sentence`(예문) 안에는 `word`(어휘)가 글자 그대로 반드시
들어가야 합니다. 빈칸 채우기 퀴즈가 예문에서 어휘를 찾아 빈칸으로 바꾸기 때문입니다.

파일을 저장하면 개발 서버가 자동으로 화면을 새로 고칩니다. 별도 빌드 없이도 반영됩니다.

## 5. 학습 기록(오답·통계) 저장 방식

학생별 학습 기록은 **Supabase(PostgreSQL)**에 저장되어, 어떤 기기에서 로그인해도
본인의 기록이 그대로 유지됩니다.

| 테이블 | 내용 |
|---|---|
| `students` | 학생 계정 (아이디 · bcrypt 해시 · 가입일 · 연구용 익명 ID `anon_code`) |
| `quiz_responses` | **문항 하나하나의 응답 기록** (분석의 핵심 원자료) |
| `word_mastery` | 학생×어휘별 정답/오답 횟수와 숙달 여부 |
| `student_wrong_words` | 현재 오답으로 남아 있는 어휘 |
| `wrong_word_reviews` | 학생이 "복습 완료"를 누른 이력 |
| `student_stats` | 누적 시도 수 / 정답 수 |
| `assignments` · `assignment_progress` | 교사 배정 학습과 수행 결과 |

저장 규칙:

- 퀴즈에서 **틀리면** 오답 목록에 추가 (같은 어휘 중복 저장 안 함)
- 퀴즈에서 **다시 맞히면** 오답 목록에서 제거
- 오답 복습 화면에서 **복습 완료**를 누르면 제거 + 복습 이력에 기록
- **2회 연속 정답**이면 그 어휘는 `숙달(mastered)` 상태가 됩니다
- **2회 이상 틀린** 어휘는 `반복 오답`으로 강조됩니다
- 학생 계정을 삭제하면 모든 학습 기록이 함께 삭제됩니다 (`on delete cascade`)

> 로그인 세션(누가 로그인했는지)은 브라우저 `grade4_student_v1` 키에
> 보관되어 새로고침해도 로그인이 풀리지 않습니다.

## 6-1. 연구 자료 내보내기

교사 대시보드 **📥 자료 내보내기** 탭에서 아래 6종을 CSV로 내려받습니다.
**학생 이름은 포함되지 않고 익명 ID(S001, S002…)만** 들어갑니다.

| 파일 | 내용 |
|---|---|
| `students` | 학생별 학습량·정답률·오답·숙달 어휘 수·학습일수 |
| `responses` | 문항 하나하나의 응답 로그 (가장 상세한 원자료) |
| `mastery` | 학생×어휘별 정답/오답 횟수와 숙달 여부 |
| `wrong-words` | 현재 오답으로 남아 있는 어휘 |
| `reviews` | 복습 완료 이력 |
| `assignments` | 배정 학습 수행 결과(점수 포함) |

엑셀에서 한글이 깨지지 않도록 UTF-8 BOM이 붙어 있어, 파일을 더블클릭하면
바로 열립니다. 통계 프로그램(SPSS·R·Python)에서도 그대로 읽을 수 있습니다.

## 7. 배포 방법 (Vercel)

저장소에 포함된 `vercel.json`이 새로고침 시에도 정상 동작하도록 설정합니다.

### GitHub 연동 (자동 배포)

1. 이 폴더를 GitHub 저장소에 올립니다.
2. [vercel.com](https://vercel.com)에서 **Add New → Project → Import**로 저장소 선택.
3. 프레임워크가 **Vite**로 자동 감지됩니다.
4. ⚠️ **Environment Variables**에 두 값을 반드시 추가합니다.
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
5. **Deploy**. 이후 GitHub에 푸시할 때마다 자동 재배포됩니다.

> 환경변수를 나중에 추가/변경하면 **Redeploy**를 한 번 해야 반영됩니다.
